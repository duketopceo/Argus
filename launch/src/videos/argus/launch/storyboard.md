# 'The witness' — storyboard (from ocellus plan §B.5)

40s · 1920x1080 · 60fps · graphite `#0C0E12` · cobalt `#7D91FF` on the mark
and one primary moment only · Schibsted Grotesk headlines · Martian Mono
numbers · eye-state glyphs are the motion vocabulary · silent-first,
CC0 foley only · legible muted.

| t | scene | action |
|---|-------|--------|
| 0–2.5s | hook | black frame → eye draws open → "Every PR gets a witness." |
| 2.5–7s | terminal | real VHS init capture; "Your keys. Your models. Your runner." |
| 7–15s | lanes | comment plate; camera dollies down 4 lanes; each eye scans → blinks → state. "Four lanes. Honest when unsure." |
| 15–22s | finding | zoom to inline finding on a diff line; cursor hovers provenance (model id, probe path, confidence). "Every finding cites its source." |
| 22–30s | cost | tally rolls `$0.004210` → cache-hit re-run rolls `$0.000000`. "Re-reviews cost nothing." |
| 30–36s | surfaces | ~1.2s cuts: HTML report · watch TUI · check text. "One witness, every surface." |
| 36–40s | end card | mark → wordmark; `npx argus-reviewer init` + repo URL. Hold ≥2s. |
