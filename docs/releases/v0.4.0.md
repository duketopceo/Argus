# Argus v0.4.0

Reviews that are quieter and easier to read, from the PR comment to the
terminal.

## What you get

- **Fewer false alarms.** Generated and fixture files are skipped by
  default, findings outside the diff are dropped, and findings in test files
  are capped.
- **One look everywhere.** The PR comment, inline comments, commit status,
  CLI, terminal UI, desk app and the offline `report.html` all use the same
  emoji-free design and wording.
- **Errors you can act on.** Every CLI failure has a stable code, a plain
  summary and a fix line. `--json` prints the error as a single JSON object.
- **No surprise spend.** Paid eval runs show the cost and ask first.
- New brand assets, README hero and demo recordings.

## Upgrade notes

- The PR comment and inline comment format changed. Comments posted by older
  versions are still recognised and will not be duplicated.
- Breaking for scripts: with `--json`, errors now print on stdout, not
  stderr. Read stdout if you parse them.
- Reviews may now report fewer findings than before. This is the filtering
  above, not a regression. Generated and fixture paths are skipped unless you
  set `review.exclude` in your config to change the list.
- The desk app and terminal UI are contributor tools in the repository, not
  part of the npm package.
- The launch film lives under `launch/` and is not published to npm.
