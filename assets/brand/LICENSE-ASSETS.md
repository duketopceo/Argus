# Brand asset licensing

The files under `assets/brand/src/` and `assets/brand/export/` are drawn for
this project and released under the repository's MIT license (`LICENSE`).

The wordmark is "argus" set in Martian Mono (wdth 87.5, wght 560, tracking
-1%), outlined to paths, with the `g` counter moved by hand. Martian Mono is
by Evil Martians and is licensed under the SIL Open Font License 1.1. The OFL
covers the font software. Outlined glyphs in a logo are artwork, not font
software, so no font file is shipped and no OFL notice is required for the
wordmark. This note records where the letterforms came from.

The MIT license covers copying the files. It does not grant the right to use
the Argus name or mark in a way that suggests your project is Argus or is
endorsed by it.
